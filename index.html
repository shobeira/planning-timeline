● Week-based planning timeline

shift+scroll to pan · ctrl+scroll to zoom · drag to reschedule · double-click timeline to add

Best experienced on a desktop or laptop display.

How to use

Goal — a single point in time.
Use for deadlines, milestones, or events.
Example: "Lease signed" on Mid March 2025.

Task — spans a period of time.
Use for ongoing work with a start and end date.
Shows as a bar on the timeline. Effort is calculated automatically.
Example: "Kitchen renovation" from Early May to Mid August 2025.

Tags — colour-coded project categories.
Click Tags to add, rename, recolour, or delete.

Statuses — track progress (Undefined → Planned → In Progress → Done).
Click Status to customise.

Filter — click status or tag pills to show/hide.

Batch Add — paste multiple items at once.
Goal: title, date, e/m/l, tag, status
Task: title, date + Nw, e/m/l, tag, status
Task: title, date, e/m/l, tag, status, end, e/m/l
